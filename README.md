# Каталог подписок

Тестовое задание на Vue 3 + Nuxt 4 + Pinia + TypeScript.

## Запуск

```bash
pnpm install
pnpm dev
```

Приложение будет доступно на адресе, который выведет Nuxt, обычно `http://localhost:3000`.

## Проверки

```bash
pnpm typecheck
pnpm build
```

## Что реализовано

- Расширяемая модель каталога: регионы, группы, типы подписок, периоды, цены, состояния карточек и информационные ограничения.
- Mock-store на Pinia с actions для выбора таба, региона и карточки подписки.
- Адаптивный UI по макету с Composition API, TypeScript и семантической разметкой.
